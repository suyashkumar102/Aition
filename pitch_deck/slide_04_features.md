# Slide 4 — Features

1. **Causal Graph Discovery** — DoWhy + PC algorithm builds the actual decision graph
2. **Proxy Path Detection** — Backdoor criterion finds hidden discrimination paths
3. **Dual Protected Attributes** — Age group + Socioeconomic group audited simultaneously
4. **Standard Fairness Benchmark** — AIF360 DPD shows model PASSING, then Aition shows what it missed
5. **Impossibility Surface** — Interactive slider showing the tradeoff between fairness definitions
6. **Surgical Debiasing** — Removes proxy variables, reweights samples, no full retraining
7. **Gemini AI Reports** — Plain-language audit report for non-technical decision-makers
8. **REST API** — FastAPI, POST /audit, POST /debias, fully documented
